# hello-world

Simple static starter site for GitHub Pages practice.

## Contents

| Path | Description |
|------|-------------|
| [`index.html`](index.html) | Home page |
| [`styles.css`](styles.css) | Basic stylesheet |
| [`images/`](images/) | Static assets (Octocat image) |

## Quick start

Open `index.html` in a browser, or enable **GitHub Pages** for this repository (Settings → Pages) and serve from the default branch root.

No build step or package manager required.
